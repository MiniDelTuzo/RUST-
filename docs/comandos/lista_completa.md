# 📋 Lista Completa de Comandos RustPlusPlus

> **Prefijo por defecto:** `!`
> El prefijo puede variar según la configuración del servidor. Usa `/help` en Discord para confirmarlo.

---

## 🎮 Comandos de Equipo

| Comando | Descripción |
|---------|-------------|
| `!afk` | Obtener los jugadores AFK actuales del equipo |
| `!alive [jugador]` | Obtener el jugador con más tiempo vivo o el tiempo de supervivencia de un compañero |
| `!connection [jugador]` | Obtener eventos de conexión recientes del equipo o de un compañero |
| `!connections` | Obtener todos los eventos de conexión recientes |
| `!leader [jugador]` | Dar/Tomar el liderazgo del equipo |
| `!offline` | Obtener los jugadores del equipo actualmente desconectados |
| `!online` | Obtener los jugadores del equipo actualmente conectados |
| `!player [jugador]` | Obtener información de un jugador específico (nombre y tiempo de juego) |
| `!players` | Obtener todos los jugadores conectados en el servidor |
| `!prox [jugador]` | Obtener la distancia a los tres compañeros más cercanos |
| `!steamid [jugador]` | Obtener el SteamID de un compañero |
| `!team` | Obtener los nombres de todos los miembros del equipo |
