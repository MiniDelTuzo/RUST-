# 📚 Comandos Organizados por Categoría

---

## **EQUIPO Y JUGADORES** 👥
Comandos relacionados con tu equipo y miembros.

```
!afk                    → Jugadores AFK del equipo
!alive [jugador]        → Tiempo de supervivencia
!connection [jugador]   → Eventos de conexión
!connections            → Todos los eventos de conexión
!leader [jugador]       → Gestionar liderazgo
!offline                → Jugadores desconectados
!online                 → Jugadores conectados
!player [jugador]       → Info de jugador específico
!players                → Todos los jugadores conectados
!prox [jugador]         → Distancia a compañeros cercanos
!steamid [jugador]      → SteamID de compañero
!team                   → Nombres de miembros del equipo
```

## **CRAFTEO E ÍTEMS** 🔨

```

!decay [item] [hp]      → Tiempo de decaimiento
!recycle <item> [cant]  → Resultado de reciclaje
!research <item>        → Costo de investigar

```

## **MERCADO Y VENDING** 🏪
Máquinas expendedoras y búsqueda de ítems.

```
!market search <t> <i>  → Buscar en máquinas
!market sub <t> <i>     → Suscribirse
!market unsub <t> <i>   → Desuscribirse
!market list            → Mis suscripciones
```

## **MARCADORES** 📍
Crea y gestiona marcadores personalizados en el mapa.

```
!marker add <nombre>    → Crear marcador
!marker remove <id>     → Eliminar marcador
!marker [nombre]        → Ir a marcador
!markers                → Listar marcadores
```

## **TRADUCCIÓN** 🌐
Traduce textos entre idiomas.

```
!tr <idioma> <texto>    → Traducir a idioma
!trf <de> <para> <txt>  → Traducir de/hacia
```

## **LEYENDA DE SÍMBOLOS**
- `[parámetro]` = Parámetro opcional
- `<parámetro>` = Parámetro obligatorio
- `→` = Descripción rápida
