## 🚀 Uso Rápido

### ¿Cómo usar los comandos?

1. **En Discord:**
   ```
   !comando [parámetros]
   ```
   Ejemplo: `!players` o `!alive @TuNombre`

2. **En el Chat de Equipo (en juego):**
   - Los mismos comandos funcionan en el chat de equipo
   - Ejemplo: `!map` te mostrará el mapa

3. **Slash Commands:**
   - Algunos comandos también tienen versión slash
   - Ejemplo: `/help`, `/credentials add`

---

## ❓ Preguntas Frecuentes

**¿Cuál es el prefijo?**
- Por defecto: `!`
- Puede variar según la configuración del servidor
- Usa `/help` en Discord para confirmarlo

**¿Dónde veo mi lista de notas/temporizadores?**
- `!notes` - Lista todas tus notas
- `!timers` - Lista todos tus temporizadores
- `!markers` - Lista todos tus marcadores

**¿Puedo cambiar el prefijo?**
- Sí, está en la configuración del bot
- Requiere permisos de administrador del servidor

## 📊 Categorías Principales

- **👥 Equipo y Jugadores** - Info sobre tu equipo
- **🚁 Eventos** - Helicóptero, Cargo, Oil Rigs, etc.
- **🔨 Crafteo e Ítems** - Información de items
- **🏪 Mercado** - Máquinas expendedoras
- **📍 Marcadores** - Mapas personalizados
- **⏱️ Temporizadores** - Recordatorios
- **📝 Notas** - Apuntes rápidos
- **🔧 Servidor** - Población, hora, uptime
- **🔊 Voz y Chat** - Comunicación
- **🌐 Traducción** - Traducir textos

## 🎮 Ejemplos de Uso

```
!players              → Ver jugadores conectados
!afk                  → Ver jugadores AFK
!cargo                → Info sobre Cargo Ship
!time                 → Hora del servidor
!craft metal          → Costo de craftear metal
!upkeep               → Tiempo de upkeep de cupboards
!team                 → Ver miembros del equipo
!market list          → Ver tus suscripciones
```
